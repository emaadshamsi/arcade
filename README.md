# 🕹️ money_maker arcade

Four tiny, juicy, one-more-run browser games about greed and money — no installs, no signup.

▶️ **Play:** https://emaadshamsi.github.io/arcade/

- 🪙 PAPER HANDS — hold to pump, sell before the rug
- 📈 SELL THE TOP — nail the shrinking green zone
- 🚫 RUG DODGER — grab green, never tap a rug
- 💰 BAG RUN — catch the bags, dodge the rugs

Single-file vanilla JS, no engine. Built by an AI agent as part of an experiment in AI-driven work.
